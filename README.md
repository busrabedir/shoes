# 👟 Kick Shoes

Kick Shoes, modern ve responsive bir ayakkabı e-ticaret uygulamasıdır. Kullanıcılar ürünleri görüntüleyebilir, detay sayfalarını inceleyebilir ve güvenli kimlik doğrulama sistemiyle giriş yapabilir. Admin paneli sayesinde ürün ekleme, güncelleme ve silme işlemleri kolayca yönetilebilir.

## ✨ Özellikler

- 🔐 Kullanıcı kayıt olma ve giriş sistemi
- ♻️ JWT tabanlı authentication & refresh token yapısı
- 🛡️ Admin korumalı dashboard sistemi
- 👟 Ürün listeleme ve detay sayfası
- ➕ Ürün ekleme, güncelleme ve silme işlemleri
- 📱 Responsive ve modern UI tasarımı
- ✅ Form validation işlemleri
- ⚡ React Query ile güçlü state & cache yönetimi
- 🔔 Toast bildirim sistemi
- 🏷️ Dinamik indirim ve yeni ürün badge sistemi


## 🛠️ Kullanılan Teknolojiler

- **React**
- **TypeScript**
- **React Router DOM**
- **TanStack Query (React Query)**
- **Axios**
- **Formik**
- **Yup**
- **Tailwind CSS**
- **React Toastify**
- **Lucide React**
